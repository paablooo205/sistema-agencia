# orbital-card-navigator

- Style: Editorial nocturno / atmosférico
- Industry: Hostelería premium (mismo sitio que `scroll-morph-hero-object.md`, "MÙN")
- Motion: Selector de ubicaciones/variantes con tres tarjetas conectadas por una **línea curva única (trayectoria de arco/órbita)**: la tarjeta central está enfocada y con foco nítido (imagen de producto + nombre de ubicación, "RIONE TRASTEVERE"), las dos laterales están desenfocadas (blur) y solo se intuyen como manchas de color. Flechas circulares a cada lado permiten desplazarse a lo largo de la curva, "orbitando" entre opciones en vez de saltar entre slides planos.
- Scroll type: Probablemente scroll horizontal o interacción por click/drag sobre la curva, no scroll vertical estándar — no se puede confirmar sin verlo correr.
- Animation type: Navegación por trayectoria curva (motion path) + profundidad de campo simulada (blur en los elementos no enfocados) para dar sensación 3D/orbital sin usar geometría 3D real.
- 3D: No — el efecto de profundidad es 2D (blur + escala), no hay objeto 3D.
- Transition: Al navegar, el foco (nitidez) se desplaza de una tarjeta a otra siguiendo la curva — la tarjeta que pasa a estar activa se desenfoca la anterior.
- Typography: Mismo sistema editorial-nocturno que el resto del sitio (serif/display en mayúsculas).
- Storytelling: Cada ubicación/variante se presenta como un punto en una órbita, no como un carrusel plano — refuerza el tono "fuera de este mundo" (astronómico) que ya establece el hero luna→cóctel.
- Useful for: Selectores de producto/ubicación/variante (3-5 opciones) donde vale la pena una navegación con más carácter que un carrusel genérico, y donde el motivo orbital/curvo tiene relación con el concepto de marca (aquí: temática lunar/espacial).
- Avoid when: Más de ~5 opciones (la curva se satura) o cuando no hay ninguna relación conceptual con "orbital/curvo" — usado sin esa relación es decoración sin narrativa.
- Source: Capturas de pantalla proporcionadas por el usuario (30-08-2026) — marca visible en pantalla: "MÙN". URL no proporcionada, sin verificar en vivo.
