# specialty-coffee-editorial-precision

- Style: Editorial / Minimalist
- Industry: Specialty coffee, F&B de precisión (tueste, torrefacción)
- Composition: Grid limpio (a menudo 3 columnas para producto/origen),
  fotografía de producto a gran escala contra fondos neutros, navegación
  simple dividida entre "comprar" y "aprender" (perfil de tueste, guías
  de preparación, historia de origen) — no todo apila hacia checkout.
- Palette: Neutra y de alto contraste — no se documentan valores hex
  concretos en la fuente consultada (resumen de búsqueda, no visita
  directa al sitio), pero el patrón es claro: base neutra, contraste
  alto entre fondo y tipografía, sin gradientes ni color saturado.
- Typography: Contraste alto, tono editorial — cabecera oscura sobre
  fondo claro (o viceversa), texto de producto/ficha técnica tratado casi
  como copy de revista, no como etiqueta de packaging.
- Storytelling: El producto (el tueste, el origen del grano) es el
  protagonista visual, no el local/la experiencia de cafetería — encaja
  con marcas que se presentan como "precisión técnica" antes que
  "artesanía de barrio".
- Useful for: Marcas de café de especialidad que quieren leerse como
  precisión/producto técnico en vez de estética rústica — como Nortea
  (paleta tierra oscuro + crema, "tueste de precisión, no estética
  rústica de pueblo").
- Avoid when: El brief pide calidez rústica/artesanal explícita (madera
  envejecida, ilustración a mano, tono "pueblo") — este patrón choca con
  esa dirección a propósito.
- Source: Investigación de sector (WebSearch, 2026) sobre sitios de
  tostadores de café de especialidad — referencia nombrada: "The Barn"
  (tostador europeo), citado como ejemplo de minimalismo europeo, paleta
  neutra y alto contraste. No se ha visitado/verificado el sitio
  directamente en esta pasada, solo el resumen de búsqueda — si este
  proyecto avanza a producción, verificar la fuente original antes de
  citarla como referencia de diseño definitiva.
